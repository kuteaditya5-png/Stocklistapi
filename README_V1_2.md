# StockLens AI v1.2 — Rolling Historical Validation

Adds a frozen 20-stock / Top-3 rolling historical validation test to Strategy Lab.

## Test
1. Deploy to Vercel.
2. Open Strategy Lab.
3. Click **Run v1.2 Rolling Validation**.
4. Review overall metrics and each sequential rolling block.

The v1.1 ranking weights and 20-stock universe are deliberately frozen. v1.2 does not tune them against the validation output.
